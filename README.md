# 💳 Java ATM Management System

## 📌 Overview
The Java ATM Management System is a console-based banking application that simulates ATM operations. It allows users to perform essential banking transactions such as deposits, withdrawals, and balance enquiries. The project demonstrates Object-Oriented Programming (OOP), Reflection API, Exception Handling, and user input validation in Java.

## ✨ Features
- Deposit money
- Withdraw money
- Balance enquiry
- Dynamic ATM card loading using Reflection API
- Multiple bank card support
- Exception handling for invalid inputs
- Input validation using Scanner
- Menu-driven console interface

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Reflection API
- Exception Handling
- Scanner Class

## 📖 Concepts Covered
- Classes & Objects
